# DnD

## About the Project

DnD is a personal programming project I created to improve my understanding of programming concepts, with a focus on objects, functions, and logical thinking.

The project gave me the opportunity to practise structuring code, working with objects, and using functions to organise and reuse functionality. By building the project, I could apply these concepts in practice and gain more experience with problem-solving and writing structured code.

## Features

- **Object-oriented programming:** Practising the use of objects to structure and organise code.
- **Functions:** Creating reusable functions to keep the code organised and maintainable.
- **Programming logic:** Developing logical solutions to make the application work as intended.
- **Problem-solving:** Applying programming concepts to solve challenges throughout development.
